# 🎬 Netflix Clone Webpage

This project is a **responsive Netflix India clone** built with **HTML** and **CSS**.  
It replicates the structure and design of Netflix’s landing page, featuring hero sections, streaming highlights, FAQ, and footer navigation.

---

## 📊 Project Overview

The webpage includes:
- **Navigation bar** with language selection and sign-in button  
- **Hero section** with a call-to-action email input  
- **Feature sections** highlighting watching on TV, mobile downloads, multi-device streaming, and kids' profiles  
- **FAQ section** with interactive expandable boxes  
- **Footer** with links to Netflix services, help, and corporate information  

---

## 🧰 Tech Stack

- **HTML5** — Webpage structure  
- **CSS3** — Styling and responsive design  
- **Google Fonts (Martel Sans)** — Typography  
- **Flexbox & Grid** — For layout and responsive positioning  
- **Video and Images** — Media integration  

---

## 🚀 Features

1. **Responsive Hero Section**  
   - Email input field and call-to-action button  
   - Background overlay with opacity effect  

2. **Streaming Features**  
   - Sections with images and videos  
   - Flexbox layout for alignment and spacing  

3. **FAQ Section**  
   - Expandable boxes with hover effect  

4. **Footer Navigation**  
   - Four-column layout with links to important pages  
   - Consistent styling and spacing
